# 研报情感分析 · Research Report Sentiment Analysis

> 面向金融研究报告（研报）的情感分析项目：基于自然语言处理（NLP），对研报文本的情感倾向（看多 / 中性 / 看空）进行自动识别，辅助量化选股与市场情绪监控。

## 📌 项目背景

券商研报中蕴含大量分析师主观判断，人工逐篇阅读成本高。本项目通过 NLP 对研报文本做情感倾向建模，将非结构化文本转化为可量化的情感信号，用于市场情绪跟踪与投研辅助。

## ✨ 主要功能

- 研报文本采集与清洗（去噪、分句、分词）
- 情感倾向分类：看多 / 中性 / 看空
- 情感强度打分与批量推理
- 结果可视化与导出

## 🛠️ 技术栈

- Python
- NLP：jieba / 预训练语言模型（如 BERT 系）
- 数据处理：pandas、numpy
